# Black Edition · Yasmin Caetano

Página de Black Friday, separada do portfólio principal. Um único `index.html`, sem build.

Para editar oferta, validade, vagas, frase de posicionamento, vídeos e depoimentos, abra o `index.html`
e mexa só no bloco **SEUS DADOS**, no começo do `<script>`. Campos deixados `""` não aparecem no site.
